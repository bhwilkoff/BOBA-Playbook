# BOBA Card & Image Schema Reference
*Generated by reconcile_all.py — source of truth for Claude Code and contributors*

## Overview

This document defines the canonical data schema for Bo Jackson Battle Arena (BOBA)
card data. All app features — database browsing, deck building, collection tracking,
and marketplace — derive their data structures from these definitions.

---

## Image File Naming Convention

All card images in `unified-cards/images/` follow this exact format:

```
{CardNumber}_{HeroName}_{ELEMENT}_P{Power}.webp    ← Hero cards
{CardNumber}_{HeroName}_{ELEMENT}_Auto.webp         ← Inspired Ink autographs
{CardNumber}_{HeroName}_HotDog.webp                 ← Hot Dog resource cards
{CardNumber}_{Name}_Play.webp                       ← Play (strategy) cards
```

**Rules:**
- Spaces and special characters in names → underscores (`_`)
- Forward slashes in card numbers → hyphens (`-`)
- Element/weapon is always **UPPERCASE**: `FIRE`, `ICE`, `HEX`, `STEEL`, `BRAWL`, `GLOW`, `GUM`, `SUPER`
- Extension is always `.webp` regardless of original source format
- No CDN URLs or source hostnames appear in any filename

**Examples:**
```
ABF-106_Bandelero_HEX_P160.webp     ← Hero, Alpha Battlefoil, Hex element
100_Wildbeard_FIRE_P105.webp        ← Hero, Griffey card #100, Fire element
PL-46_10_10_Unfair_Play.webp        ← Play card
HD-1_Dirty-Water-Dan_HotDog.webp    ← Hot Dog card
MBFA-18_Chief_STEEL_Auto.webp       ← Inspired Ink autograph
```

## cards.json Schema

Located at `unified-cards/data/cards.json`. Array of card objects.

```json
{
  "cardNumber":         "ABF-106",
  "bvId":              106,
  "name":              "Bandelero",
  "hero":              "Bandelero",
  "cardType":          "Hero",

  "set":               "Alpha",
  "subSet":            "2025 Update",
  "variation":         "Alpha Battlefoil",
  "treatment":         "Alpha Battlefoil",
  "element":           "HEX",
  "power":             160,

  "playCost":          null,
  "playAbility":       null,
  "isBonusPlay":       false,
  "isHTD":             false,
  "dbs":               null,
  "dbsTier":           null,

  "athleteInspiration": "Randy Johnson",
  "isInspiredInk":     false,

  "imageFile":         "ABF-106_Bandelero_HEX_P160.webp",
  "imageSource":       "BV",
  "imageAvailable":    true,

  "searchTokens": ["abf", "106", "bandelero", "hex", "alpha", "battlefoil", "160"]
}
```

### Field Reference

| Field | Type | Description |
|---|---|---|
| `cardNumber` | string | External card number (e.g. `ABF-106`, `PL-46`, `100`). Primary key. |
| `bvId` | integer\|null | Bazooka Vault internal ID (1–17743). Used to fetch BV page. |
| `name` | string | Display name of the hero or play card. |
| `hero` | string | Hero name from the master checklist. May differ from `name` (BV name). |
| `cardType` | string | `"Hero"`, `"Play"`, or `"HotDog"`. |
| `set` | string | Top-level set: `"Alpha"`, `"Griffey"`, `"2024 National Show Starter Set"`, `"World Champions"`, `"Superfan Series"`. |
| `subSet` | string | Sub-release within a set: `"2024 Release"`, `"2025 Update"`, `"2025 Release"`, `"Blast"`, `"Cyber"`, etc. |
| `variation` | string | Full variation label from checklist: `"Alpha Battlefoil"`, `"Base (Paper)"`, `"Mixtape Battlefoil"`, etc. |
| `treatment` | string | Treatment code/label (may match `variation`). |
| `element` | string | Weapon/element type — always UPPERCASE: `FIRE`, `ICE`, `HEX`, `STEEL`, `BRAWL`, `GLOW`, `GUM`, `SUPER`. |
| `power` | integer\|null | Card power level (e.g. 160). Null for Play and HotDog cards. |
| `playCost` | integer\|null | Hot Dog cost to play this Play card. Hero cards = null. |
| `playAbility` | string\|null | Text describing the Play card's effect. Null for Hero/HotDog. |
| `isBonusPlay` | boolean | True if this Play has `BPL-` card number or treatment "Bonus Plays". Bonus Plays sit in a separate 0–15 slot pool in the Deck Builder. |
| `isHTD` | boolean | True if this Play has `HTD-` card number or treatment "Home Team Discount". HTD plays cost 0 Hot Dogs but typically carry a high DBS value. |
| `dbs` | integer\|null | Deck Balancing System value (1–110). Populated by step 13 from official deck builder scrape. Null for non-Play cards or unmatched plays. |
| `dbsTier` | string\|null | DBS tier bucket: `"Low"` (0–20), `"Medium"` (21–40), `"High"` (41–60), `"Very High"` (61+). Used for UI badges and filter chips. |
| `athleteInspiration` | string\|null | Real athlete who inspired this hero (e.g. `"Randy Johnson"`). Null if fictional/unnamed. |
| `isInspiredInk` | boolean | True if this card is an Inspired Ink on-card autograph. |
| `imageFile` | string\|null | Canonical filename in `unified-cards/images/`. Null if no image. |
| `imageSource` | string\|null | Source of the best image: `"BV"`, `"GCS"`, `"RADISH"`, or `"EBAY"`. |
| `imageAvailable` | boolean | True if an image file exists in the unified directory. |
| `searchTokens` | string[] | Lowercase word tokens for full-text search. Not sent to iOS bundle (use cards-slim.json). |

## Claude Code Integration Notes

When building the BOBA app, Claude Code should:

1. **Card images** are served from `unified-cards/images/` committed to the GitHub repo, or from GitHub Pages CDN.
   Reference format: `/{imageFile}` relative to the images base URL.

2. **Filtering** should use the `element`, `set`, `treatment`, `cardType` fields.
   Never filter by parsing the filename — always use the JSON fields.

3. **Search** uses `searchTokens` (web) or server-side text search (iOS with SwiftData).
   The `search-index.json` maps token → array of bobaIds for O(1) web lookup.

4. **Image fallback**: if `imageAvailable` is false, show a placeholder image.
   The placeholder should display the `cardNumber` and `element` color.

5. **Card number is the primary key**. It is unique across all sets.
   BV ID (`bvId`) is a secondary reference used only for re-fetching BV data.

6. **No CDN URLs** appear anywhere in the app data. All images are self-hosted.
